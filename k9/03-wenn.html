=WENN(Frage;"Ja";"Nein")
Calc stellt eine Frage. Die Antwort ist nur Ja oder Nein.

ZeichenFragefür Zahlenfür Text

Text steht immer in "Anführungszeichen". Zahlen ohne.

Gegenfrage: Dreh die Frage um und tausch die Antworten. Das Ergebnis bleibt gleich. =WENN(A5>=12;"Ja";"Nein") ist dasselbe wie =WENN(A5<12;"Nein";"Ja"). Aus >= wird <, aus <= wird >.

Merke (Hefteintrag)

  • WENN stellt eine Frage, auf die es nur Ja oder Nein gibt: =WENN(Frage;"Ja";"Nein")
  • Beispiel: =WENN(A6="Katze";"Ja";"Nein") – Steht in A6 Katze?
  • Vergleichen: = gleich · <> ungleich · < kleiner · > größer · <= höchstens · >= mindestens
  • Text steht immer in "Anführungszeichen". Zahlen ohne.
  • Statt "Ja" und "Nein" darf jeder Text stehen, z. B. "bestanden".
  • Gegenfrage: Frage umdrehen und Antworten tauschen – das Ergebnis bleibt gleich. Aus <= wird >.
