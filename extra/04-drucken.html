Drucken wie ein Profi

Zusatzmodul · freiwillig ⏱ ca. 35 Minuten brauchst du bei jeder Abgabe
  • Ich prüfe mit der Druckvorschau, wie der Ausdruck aussieht.
  • Ich stelle Querformat, „auf eine Seite“ und eine Kopfzeile ein.
  • Ich lege fest, was gedruckt wird – und speichere als PDF.

1 Das Problem 5 Min

💡 Deine Notenliste ist 30 cm breit. Auf ein A4-Blatt hochkant passen nur etwa 17 cm.

Jetzt du: Was passiert, wenn du einfach auf Drucken klickst?

2 Druckvorschau-Simulator 8 Min

Erst schauen, dann drucken: Datei → Druckvorschau (Strg+Umschalt+O)
Ich will …So geht's
QuerformatFormat → Seitenvorlage … → Seite → Ausrichtung: Querformat
alles auf 1 SeiteFormat → Seitenvorlage … → Tabelle → Skalierungsmodus: Druckbereich auf Anzahl der Seiten anpassen → 1
Name und Datum obenFormat → Seitenvorlage … → Kopfzeile → Bearbeiten …
Überschrift auf jeder SeiteFormat → Druckbereiche → Bearbeiten … → Wiederholungszeile
nur einen Teil druckenBereich markieren → Format → Druckbereiche → Festlegen
als PDF abgebenDatei → Exportieren als PDF …

3 Jetzt in LibreOffice Calc 15 Min

Mach die Listen druckfertig. Die Checkliste in der Datei hilft dir. Zum Schluss: als PDF exportieren.

ODS Übungsdateix04-drucken.ods ODS LösungsdateiNotenliste fertig eingestellt – schau in die Druckvorschau
  • BasisAufgabe 1 · Notenliste: Querformat, auf 1 Seite, Kopfzeile, PDF.
  • PlusAufgabe 2 · Lange Liste: Die Überschrift soll auf jeder Seite stehen.
  • ExpeditionFreiwillig: Nur die Tabelle drucken, nicht die Notizen.

4 Kurz-Check 3 Min

Merke (Hefteintrag)

  • Erst schauen, dann drucken: Datei → Druckvorschau.
  • Querformat: Format → Seitenvorlage … → Seite → Querformat.
  • Auf 1 Seite: Format → Seitenvorlage … → Tabelle → Skalierungsmodus → Anzahl der Seiten: 1.
  • Kopfzeile: Format → Seitenvorlage … → Kopfzeile → Bearbeiten …
  • Nur einen Teil: markieren → Format → Druckbereiche → Festlegen. Abgabe: Datei → Exportieren als PDF.
