# Calc-Kurs – Tabellenkalkulation mit LibreOffice Calc

🇬🇧 [English version](README.md)

Freier Lernpfad für **LibreOffice Calc** an der Mittelschule in Bayern, Jahrgangsstufe 8 und 9.

**Live:** https://calc.herrseibert.de

## Inhalt

| Ordner | Was ist drin? |
|---|---|
| `index.html` | Kursübersicht |
| `k8/` | Klasse 8: erste Schritte, Formeln, Funktionen, Ausfüllen, absolute Bezüge, Diagramme, Projekt Klassenfahrt |
| `k9/` | Klasse 9: Fehlerdetektiv, Prozentrechnung, WENN (3 Teile), bedingte Formatierung (2 Teile), Fit für die Probe |
| `extra/` | Freiwillige Zusatzmodule (z. B. ZÄHLENWENN, SVERWEIS, Datum, Text, Zufall) |
| `downloads/` | Übungsdateien (`.ods`) mit passenden Lösungen (`-LOESUNG.ods`) |
| `assets/` | Stil, Skripte (Mini-Tabelle, Diagramme, Fragen) und Sprachhilfen |

Die Übungsdateien prüfen sich selbst: Kontrollzellen zeigen an, ob eine Formel stimmt.

**Sprachhilfe (DaZ):** Die Seiten sind deutsch. Wer möchte, blendet Übersetzungen ein
(z. B. Englisch, Ukrainisch, Arabisch, Russisch). Calc-Begriffe bleiben deutsch.

## Benutzen

Die Seite ist rein statisch – ohne externe Schriften, Cookies und Tracking.
Zum lokalen Ansehen im heruntergeladenen Ordner starten:

```bash
python3 -m http.server 8765
```

Dann im Browser http://localhost:8765 öffnen.

Getestet mit LibreOffice 24.2.
